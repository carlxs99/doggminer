- Streak and Turbo 420 live in dogg_shift: the streak multiplier is frozen per shift at start/claim (shift_boost) and Turbo is a checkpointed time window that earns the rate twice; src/lib/mining.ts mirrors both (streakBoost, TURBO_MS) so the live counter matches what the server pays.
- Referral-farm enforcement uses dogg_referral_farm_check with corroborated fixed first-qualification latency and paced registrations; run at first qualification, referral claim, withdrawal request and before payout. Audit bans, preserve balances and unban exemptions; raw popularity or inactivity alone must not ban. This replaces registration-speed-only enforcement.
- Admin broadcasts: the preview sent to the admin uploads the image to Telegram and its file_id is reused for everyone (no public storage); the every-minute job /api/public/jobs/broadcast sends one leased batch per run and advances a telegram_id cursor per wave, so messages aren't repeated.
- LP partner: src/lib/lp.server.ts reads the wallet's DeDust position contract (pool get_position_address, first coins field = LP) and converts it to GRAM via get_pool_data; the server passes p_lp to dogg_shift (checkpointed rate change, rate = greatest(miner, LP daily)) and refreshes it right before dogg_withdraw (fee 0 for lp_active); src/lib/lp.ts mirrors the numbers for the client.
- DOGG Mines: the board is generated and kept in dogg_mines_games (dogg_mines DB function, row-locked, ledger kind 'game' excluded from PnL) and only revealed after the round ends; src/lib/mines.ts mirrors dogg_mines_mult so the shown multipliers match payouts.
- Spin the Blunt: the slot is drawn by dogg_spin in the DB (weighted, ~4.5% house edge, FREE re-spins inside the same call, ledger kind 'game'); src/lib/spin.ts mirrors slot order and weights so the wheel lands where the server paid.
- Flip the DOGG Coin: dogg_flip in the DB draws heads/tails 50/50 and pays x1.95 (ledger kind 'game', labels hist.flipBet/flipWin feed the public history view); src/lib/flip.ts mirrors the multiplier.
